## 👨‍💻 About Me

QA Automation Engineer / SDET with **4+ years** of hands-on experience shipping quality software across web, mobile and backend systems, working with a senior-level, end-to-end quality mindset. I design automation frameworks from scratch, shift testing left into CI/CD, and help teams release faster with confidence.

- 🏗️ Build scalable, maintainable **automation frameworks** (Page Object Model, data-driven, fixtures, custom reporters)
- 📝 Write **standard, traceable test cases** (ID, priority, type, preconditions, steps, expected result) and prove docs = code with automated checks
- 🔌 Deep **API testing** — REST contracts, auth flows, negative/boundary scenarios, schema validation
- ⚡ **Performance & load testing** — smoke, load, stress, spike and soak profiles with thresholds
- 📱 **Mobile automation** (Android / iOS) with Appium
- 🔁 **CI/CD quality gates** — type check, lint, traceability check and tests on every push
- 🐞 **Honest defect reporting** — real site/API bugs are logged and asserted as known defects, never hidden
